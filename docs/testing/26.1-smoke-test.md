# Minecraft 26.1 patch compatibility smoke test

The patch-compatibility candidate below is the preserved `1.3.1` release
artifact. The later Guard Profile persistence matrix and current development
work target `1.4.0`; results are intentionally kept separate so historical
artifact evidence is not relabeled.

## Candidate

- Rally of the Guard: `rallyguard-fabric-26.1-1.3.1.jar`
- SHA-256: `C7FE3D625979888C893896A971FB7B00E930F4826435670FB3AFF298B8652A54`
- Fabric Loader: `0.18.4`
- Fabric API: `0.144.3+26.1`
- Guard Villagers: `2.1.3-26.1` (CurseForge file `7863507`)
- MidnightLib: `1.9.2+26.1-fabric`
- Java: `25`

The candidate was copied outside `build/` before patch-version testing. The
same preserved bytes were placed on the runtime classpath for all three game
versions; no rebuild occurred between the 26.1.1 and 26.1.2 runs.
